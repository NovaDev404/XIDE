## Features
- [ ] Xcode-like IDE design
- [ ] Error checking, suggestions, and debugging
- [ ] Build/compile apps with xtool
- [ ] Install apps directly to device
- [ ] Preview apps with iOS VM
- [ ] Visual "storyboard" editor
- [ ] Import xcodeproj apps
- [ ] iOS device log

- Tauri + React
- xtool
- SourceKit-LSP
- isideload
- CodeMirror
- HackiOS
